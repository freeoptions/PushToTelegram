# PushToTelegram

一个给自己用的 B 站 UP 投稿提醒小工具。

## 功能

- 手动点击检查 UP 主最新投稿
- 只把没发过的投稿链接推送到 Telegram 群组
- 支持多个 UP 主
- 本地保存配置、日志和去重记录
- 可选低频自动检查，`0` 表示关闭
- 多个 UP 主之间自动加入随机请求间隔，降低风控概率

## 运行

1. 安装 Python 3.11+
2. 安装依赖

```powershell
pip install -r requirements.txt
```

3. 启动

```powershell
python app.py
```

## 配置说明

- `Telegram Bot Token`：你的机器人 token
- `Telegram Chat ID`：群组 chat id
- `UP 主列表`：每行一个 UID，支持 `UID|备注名`
- `B 站 Cookie`：默认可留空；如果触发风控，再把浏览器里复制出来的整段 Cookie 填进去
- `首次同步条数`：第一次检查某个 UP 时，默认补发最近 10 条投稿
- `自动检查间隔(小时)`：`0` 为关闭，`12` 表示每天检查 2 次
- `UP 请求间隔(秒)`：检查多个 UP 时的基础间隔，默认 `8`
- `消息发送间隔(秒)`：连续发多条 Telegram 消息时的基础间隔，默认 `1.5`

## 说明

- 第一次检查某个 UP 时，默认发送最近 10 条投稿
- 后续检查只发送新增投稿
- 遇到 B 站常见风控错误 `-352` 或 `-412` 时，程序会停止后续请求，避免继续冲接口
